计算机原理部分 — 基于迈克尔逊干涉原理的全光纤高灵敏度音频传感研究

计算机成员：葛泳杰（计算机学院、软件学院、网络空间安全学院）
核心方向：后端 Python 算法提升系统鲁棒性，实现”软件定义传感器”
对应申请书职责：Python 实时采集、数字滤波及 GUI 界面开发；利用 Python 算法弥补大空气间隙带来的信号衰减

一、软件定义传感器：总体架构

本项目提出”软件定义传感器”（Software-Defined Sensor, SDS）理念，将传统光纤传感系统中由硬件完成的信号处理、补偿、解调功能，通过后端 Python 算法实现。核心思路是：硬件做减法——仅保留光路与 ADC 采集，采用 300μm-500μm 大容错 F-P 腔体降低封装难度；软件做加法——通过数字滤波与 AI 算法弥补大空气间隙带来的信号衰减与噪声干扰。

二、信号链路中的降质因素分析

2.1 F-P 腔空气间隙衰减

本项目采用非本征 F-P 干涉结构（Extrinsic F-P Interferometric, EFPI），光纤端面与 Mylar 薄膜之间形成 300μm-500μm 的空气间隙。声波引起 Mylar 薄膜振动，改变腔长，从而调制干涉光强。

空气间隙带来的影响具有两面性：

正面：大间隙（300μm-500μm）显著降低了装配难度与撞膜风险，提升了系统鲁棒性，是本项目的核心设计创新。

负面：光在空气间隙中发散后部分耦合回光纤，导致光功率衰减；同时，间隙中空气的热扰动引入附加噪声。衰减量近似满足：

$$L_{gap} = -10\log_{10}\left(\frac{1}{1 + (2z \cdot NA / d_{fiber})^2}\right) \quad \text{(dB)}$$

其中 $z$ 为 F-P 腔长（300-500μm），$NA$ 为光纤数值孔径，$d_{fiber}$ 为纤芯直径。

软件补偿思路：将 F-P 腔体的光-声调制过程建模为可学习的非线性映射 $f: p(t) \rightarrow I(t)$，其中 $p(t)$ 为声压信号，$I(t)$ 为接收光强。通过 AI 模型从含噪 $I(t)$ 中逆向恢复 $p(t)$。

2.2 干涉仪工作点漂移

迈克尔逊/F-P 干涉仪对环境温度、低频振动极为敏感，工作点（偏置相位）会随时间缓慢漂移，导致信号失真甚至衰减。这是光纤干涉类传感器的共性问题。

软件补偿思路：利用自适应数字滤波算法实时跟踪工作点漂移，通过反馈补偿维持干涉仪在灵敏度最高的正交工作点（ quadrature point）附近。

2.3 噪声来源

噪声类型 来源 特性 传统方法局限
光功率噪声 660nm 激光器输出波动 高斯噪声，低频漂移 滤波可部分抑制
散粒噪声（shot noise） APD 光生载流子随机性 非高斯脉冲噪声 传统滤波无效
热噪声 TIA 电路电阻热运动 高斯白噪声 低通滤波有损信号
空气间隙热扰动 腔内空气分子热运动 低频噪声 需自适应方法
环境振动噪声 外界机械振动耦合 非平稳噪声 需屏蔽+算法联合
工作点漂移 温度/应力变化导致 极低频偏置漂移 需闭环补偿

三、AI 模型算法

借鉴”AI+物理实验（光纤传感方向）”完整版实验方案第 2.2 节的三种 AI 模型架构，针对本项目的 F-P 干涉音频传感信号特性进行适配改造。三种模型分别解决链路中不同环节的信号降质问题。

3.1 自编码器（Autoencoder, AE）— 宽带噪声抑制与工作点漂移补偿

原理：无监督学习，编码器将含噪干涉信号压缩为低维特征向量（滤除噪声维度，同时将干涉仪工作点漂移这种低频偏置作为冗余信息自动丢弃），解码器重构为干净的音频信号。

适配改造：

  • 输入层：2048 点（约 46ms @44.1kHz），包含约 2-3 个声波周期
  • 编码器：Conv1D(16, kernel=5) → Conv1D(32, kernel=5) → Conv1D(64, kernel=3)，每层 stride=2，ReLU 激活
  • 瓶颈层：128 维潜变量
  • 解码器：转置 Conv1D 对称结构
  • 损失函数：MSE + 感知损失（perceptual loss），提升听觉质量

在本项目中的角色：作为预处理环节，抑制光功率漂移、热噪声和工作点漂移，提升整体信噪比约 8-12dB。

3.2 LSTM — 时序依赖建模与 F-P 腔响应补偿

原理：LSTM 的门控机制可捕捉声波信号的长期时序依赖，区分声波本身的时序规律与 F-P 腔体非线性响应、空气热扰动引入的乘性/加性噪声。

适配改造：

  • 输入：含噪信号分帧（帧长 256 点，帧移 128），Hanning 窗加窗
  • LSTM 层：2 层双向 LSTM，隐藏单元 256，dropout=0.3
  • 输出：全连接层输出补偿后的帧信号
  • 重建：重叠相加（OLA）恢复连续音频

核心创新：将 F-P 腔体的声-光调制过程视为一个非线性动态系统，利用 LSTM 隐式学习其状态转移规律。训练时使用成对数据（参考麦克风信号 vs. F-P 传感器信号），让 LSTM 学习从畸变信号到真实声压的逆映射。

在本项目中的角色：核心的腔体响应补偿模块，解决 F-P 腔体非线性和空气热扰动导致的信号畸变。

3.3 U-Net — 脉冲噪声抑制与微弱信号细节恢复

原理：编码-解码 + 跳跃连接结构，保留音频信号的时域细节特征，特别适合抑制 APD 散粒噪声产生的脉冲型干扰以及恢复微弱声波信号的细节。

适配改造：

  • 一维 U-Net（1D U-Net），适配音频时域信号
  • 编码端：5 层 Conv1D + BatchNorm + ReLU + MaxPool，通道数倍增 16→32→64→128→256
  • 解码端：5 层 UpConv1D + Skip Connection + ReLU，通道数对称递减
  • 损失函数：MSE + 多尺度频谱一致性损失（Multi-Resolution STFT Loss），同时约束时域波形精度和频域能量分布

在本项目中的角色：作为最后一级精修模块，修复 AE 和 LSTM 未能完全抑制的散粒噪声脉冲残留。在微弱声音信号（如远处说话声、烧伤皮肤脉搏信号）场景下优势最为明显，直接决定了系统能否检测到目标的微弱声学事件。

五、自适应参数调优

软件定义传感器的核心优势之一：自动适配不同实验条件，无需人工干预。

5.1 噪声类型自动识别

对输入信号做短时傅里叶变换（STFT），提取时频特征，送入轻量级分类器（CNN + Softmax），自动判断当前主导噪声类型，动态调整处理链路：

检测到的噪声模式 启用模块 说明
低频漂移主导 AE 强模式 + 高通预滤波 工作点漂移严重时
脉冲噪声突出 启用 U-Net 级 APD 偏压不稳时
幅度包络畸变 启用 LSTM 补偿 腔体非线性明显时
正常 全链路轻量模式 降低计算延迟

6.1 与电子/光学成员的协作分工

成员 专业 职责 输入 → 输出
光电成员（1人） 光电信息 薄膜工艺、腔体平行度调试 封装好的 F-P 探头
电科成员（1人） 电子科学 TIA 电路设计、信号分路硬件 放大的电信号
电磁成员（2人） 电磁场 物理封装抗干扰设计、数据分析 屏蔽方案、数据分析
计算机成员（1人） 计算机 Python 算法 + GUI 可听音频 + 可视化

6.2 软件工作分解

对应申请书中的”Python 实时采集、数字滤波及 GUI 界面开发”，具体分解为：

  1. 串口实时采集（已完成，串口采集.py）：通过 CH340 USB 转串口接收 STM32 ADC 数据，支持自动串口识别、实时进度显示、CSV/WAV 双格式保存
  2. CSV → WAV 还原（已完成，t1还原wav.py）：支持单声道/双声道，自动去直流+归一化，性能优化后处理速度达 ~1s/2min音频
  3. 数字滤波：级联高通（去直流）+ 带通（20Hz-20kHz）+ 自适应陷波（抑制特定干扰频率）
  4. GUI 示波器（已完成，示波器.py）：PySide6 + pyqtgraph 实现，含时域波形 + FFT 频谱 + 播放控制，机械神教风格 UI
  5. AI 降噪模块（本报告第三、四章）：AE + LSTM + U-Net 三级级联处理
  6. 空气间隙补偿（本报告第五章）：基于导频估计或 LSTM 隐式学习的自适应补偿

6.3 与参考方案（AI+物理实验方案 2.2 节）的对比

维度 参考方案（光纤干涉+FBG） 本项目（F-P 腔音频传感）
传感器类型 M-Z 光纤干涉仪 / FBG 非本征 F-P 干涉腔（EFPI）
被测量 微振动、微小应变、温度 声压信号（音频 20Hz-20kHz）
AI 输入 干涉信号强度波形 APD 输出电信号
AI 输出 重构干涉信号 + 物理参数 重构音频信号
核心难点 极低 SNR 下恢复周期性信号 腔体非线性 + 工作点漂移 + 大间隙衰减
模型适配 保留 AE/LSTM/U-Net 架构，输入输出改为音频采样点
